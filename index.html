📘 Master Password Configuration & Recovery Guide
  • Dashboard Updates: When you change your password above, it is instantly written to your browser's persistent storage key (esellerstore_admin_auth) and synchronized with IndexedDB.
  • Default Hardcoded Fallback: If storage is cleared or accessed from a fresh browser, the system falls back to default credentials: admin@esellerstore.com / admin123.
  • Updating Default in Codebase: To permanently customize the initial default password in source files, update the getAdminAuth() function in app-bundle.js / dokan-engine.js.
